# Portal Atto

Site institucional da Atto para adesao a atas de registro de precos (mobiliario escolar, inclusao, playground, uniformes e tecnologia para redes municipais de ensino).

## Estrutura do projeto

Arquivo index.html: pagina inicial.
Arquivo ata.html: detalhes de atas de registro de precos.
Arquivo produtos.html: catalogo de produtos.
Arquivo quem-somos.html: pagina institucional.
Pasta assets: imagens e videos.
Pasta _ds: design system (estilos e scripts).
Arquivo support.js: script de apoio da pagina.
Arquivo vercel.json: configuracao de deploy na Vercel.

## Deploy

O deploy e feito automaticamente pela Vercel a cada push na branch main.
